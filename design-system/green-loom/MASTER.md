# Design System — Green Loom Landing v1.3

**Guide:** [apple.com](https://www.apple.com/) styling patterns  
**Accent:** Loom Green `#39823D` (replaces Apple link blue)

## Adopted from Apple

| Pattern | Application |
|---------|-------------|
| Black translucent sticky nav | Logo + Follow only |
| Stacked full-bleed tiles | Hero / problem / mission / goals / audience / follow / FAQ |
| Massive sans display type | Figtree, tight tracking, short lines |
| Sparse copy | Brand. One subline. Link CTAs. |
| `Learn more ›` link CTAs | Green accent + chevron |
| `#f5f5f7` surface tiles | Alternating with white / black |
| Pill buttons | Follow submit only |
| Centered tile composition | One idea per section |

## Brand rules kept

- Loom Green accent (not Apple blue)
- Logo once (nav only)
- No product vapor / fake social proof
- Conversion = Follow updates email
